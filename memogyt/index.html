Grow your ideas with AI.

Memogyt is a notebook for the AI era, with cloud sync through GitHub.
Capture ideas offline, connect with your favorite AI, and turn a conversation into your next step.

Your everyday notebook

  • Automatic local saving and offline editing.
  • Folders, filename and full-text search.
  • Markdown preview with headings, lists and tables.
  • Japanese and English interfaces with multiple themes.

Optional connections

Preview and edit text before opening ChatGPT, Claude or Codex. Copy and paste where direct text handoff is unavailable. You submit the message in the destination app.

GitHub sync runs when requested, with up to 100 changes per operation. It requires a GitHub account, an initialized repository and a Personal Access Token with suitable permissions. Local notes require none of these.

Availability

Windows Store certification is complete. Mac, iPhone and AI-sharing release preparation is ongoing. Verified public download links will be added when available.

LOCAL NOTES · MARKDOWN · SHARE

思いつきを、AIと育てる。

Memogytは、AI時代のクラウド（GitHub）同期型メモ帳です。
オフラインでアイデアを書き留め、好きなAIへつないで、壁打ちから次の一歩へ。

まずは、書くだけ

オフラインで作成・編集。ファイル名や本文で検索でき、フォルダで整理できます。

Markdownで整理

見出し・箇条書き・表をプレビュー。日本語／英語と複数のテーマを切り替えられます。

必要なときに共有

本文を確認・編集してChatGPT、Claude、Codexへ。対応状況に応じて、コピーして開いた先へ貼り付けます。投稿は利用者が行います。

GitHub連携は任意です

入力のたびには送信しません。同期ボタンから変更を確認して反映し、1回の同期は最大100件。競合したメモは確認を後回しにできます。

GitHub連携にはGitHubアカウント、初期化済みリポジトリ、必要な権限のPersonal Access Tokenが必要です。通常のメモ利用には不要です。

配布について

Windows版のStore認定は完了しています。Mac・iPhone版とAI共有機能の正式配布は準備中です。公開済みの配布先と提供機能を確認してから、このページへ掲載します。
