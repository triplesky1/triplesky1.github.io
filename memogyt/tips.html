MEMOGYT · TIPS

Small notes. Next steps.

Capture an idea now. Organize it and share it when you are ready.

1. Capture ideas offline

On the train or between tasks, write a short note on This device. Editing and local saving work offline. Start with a title and a few rough lines; polish them later.

2. Turn a note into a useful conversation

  1. Open the note and choose Share.
  2. Choose an AI destination and review or edit the preview. This does not change your original note.
  3. Press Copy, then Send / Open.
  4. Paste into the destination if the text was not filled in, review it and send it yourself.

Copy and paste is the dependable workflow. Direct text handoff is a convenience that varies with the device, installed app and sign-in state. Memogyt does not fetch AI replies automatically. You need a connection and any account required by the destination.

For a second opinion, open Share again and choose another AI. Set your usual destination as the default to save time. Check for private information before sharing.

3. Give AI a clear question

Add your goal, constraints and the question you want answered. For example:

Idea: a notebook for quick observations.
Goal: make it easy to capture one sentence offline.
Constraint: keep the first version simple.
Question: what is the smallest useful version, and what could go wrong?

4. Organize with Markdown

Use a .md note for headings, lists and tables, then check the preview. Keep a short summary at the top so that future you can find the point quickly.

# Weekend idea

- Goal: capture a quick thought
- Next step: try a small example

| Question | Next step |
| --- | --- |
| Is it useful? | Test one workflow |

5. Sync deliberately with GitHub

GitHub sync is optional. It requires a GitHub account, an initialized repository and a Personal Access Token with suitable permissions. When connected, review the proposed changes before running sync. An offline edit is local until you sync; the other device also needs to sync to receive it. Each operation handles up to 100 changes.

Do not put tokens or passwords in notes intended for sharing. Never include your PAT in a support inquiry. Git history can retain previously committed content.

日本語 · 使い方のヒント

思いつきを、次の一歩へ。

まず書き留め、あとから整理。必要になったらAIへつなぎます。

1. オフラインで思いつきを残す

電車の中や作業の合間には「この端末」で短いメモを書きます。編集と端末内への保存はオフラインでも使えます。題名と数行だけで十分。整理はあとからできます。

2. メモをAIとの壁打ちへ

  1. メモを開き「共有」を選びます。
  2. 共有先を選び、プレビューで内容を確認・編集します。原文は変わりません。
  3. 「コピー」、続けて「送信／開く」を押します。
  4. 本文が入っていなければ、開いた先に貼り付け、確認して自分で送信します。

コピー＆ペーストが基本です。本文を直接渡す機能は、端末・インストール済みアプリ・ログイン状態によって使える便利な補助機能です。AIの回答を自動取得する機能はありません。共有先で必要な通信やアカウントは別途用意します。

別の意見も聞きたい場合は、もう一度共有を開いて別のAIを選びます。普段使う共有先を既定にすると選ぶ手間を減らせます。共有前に個人情報や秘密が含まれていないか確認しましょう。

3. 質問をひとつ添える

目的・制約・聞きたいことを添えると、壁打ちを始めやすくなります。

アイデア：気づきを素早く残すメモ帳
目的：オフラインで一文だけでも残せるようにする
制約：初版はシンプルにする
質問：最小限で役立つ形は？ どんな問題がありそう？

4. Markdownで整理する

.mdのメモなら、見出し・箇条書き・表を使ってプレビューできます。冒頭に短い要点を残すと、あとで読み返しやすくなります。上の英語欄にあるMarkdownの例も試せます。

5. GitHub同期は確認して実行

GitHub連携は任意です。GitHubアカウント、初期化済みリポジトリ、必要な権限のPersonal Access Tokenが必要です。接続後は変更内容を確認して同期を実行します。オフラインで書いた内容は同期するまで端末内にあります。別の端末でも受信のための同期が必要です。1回の操作は最大100件です。

共有するメモにはトークンやパスワードを書かず、問い合わせにもPATを含めないでください。Gitの履歴には過去にコミットした内容が残ることがあります。
